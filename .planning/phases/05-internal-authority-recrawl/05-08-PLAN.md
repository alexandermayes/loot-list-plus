## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local main → origin/main → Vercel production | Deploy two publishes the final state the recrawl is spent against |
| production CDN → probe verdict | An edge node's response is what the probe judges; a single stale node would produce a false verdict |
| `.env.local` secrets → inspection → committed log | Credential material must not reach a committed file through a pasted API response |
| probe and inspection verdicts → the recrawl log | A row in this log is read later as evidence a URL was ready, by someone who will not re-check |
