    Structure the script as small pure functions with one thin I/O shell, so the parsers are unit-testable without a network.

    `parse_sitemap(xml_text)` returns a dict of loc to lastmod. Use `xml.etree.ElementTree` with the explicit namespace map `{"sm": "http://www.sitemaps.org/schemas/sitemap/0.9"}` and `findall("sm:url", NS)`. A bare tag-name search silently returns an empty list against the default-namespaced document Next.js emits, and an empty parse that reports success is worse than a crash, so raise a named error when the parse yields zero URLs from non-empty input.

    `extract_canonical(html)` returns the href of the first `link` element whose rel is canonical, or None. Match case-insensitively and tolerate attribute order, since the rel attribute may precede or follow href.

    `has_noindex_meta(html)` returns True when a `meta` element with a name of robots carries a content value containing noindex, matched case-insensitively.

    `has_noindex_header(headers)` returns True when an `X-Robots-Tag` response header contains noindex, again case-insensitively.

    `contains_anchor(html, anchor_text, href)` returns True only when both the exact anchor text and the exact href appear in the document. Compare the anchor text as an exact UTF-8 substring with no normalization: this is the byte-level parity check that ties what shipped to the approved copy table, so a curly quote silently matching a straight one would defeat the point. Unescape the common HTML entities for apostrophe and ampersand before comparing, and document that as the one normalization performed.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local machine → origin/main → Vercel production | A push publishes ninety-six commits to a public host; anything reachable after the push is reachable by anyone |
| probe script → production HTTP | Untrusted response bodies and headers are parsed by the probe; a malformed or hostile document must fail loudly rather than parse to a passing result |
| Vercel production → Googlebot | What the sitemap and page metadata assert about canonical URLs and freshness is what crawlers act on |
