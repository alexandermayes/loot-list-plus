- **[EXPN-01 unclassified edge probe, resolved by owner decision D-16]** EXPN-01's wording says bosses are "seeded from a manifest keyed on `wowhead_id`"; D-01 makes bosses manifest-only (no boss rows, no migration), and the `wowhead_id`-keyed part of the manifest is its item map, empty for Forever today. - **[EXPN-05 unclassified edge probe, flagged, unresolved]** Idempotency is read-then-insert because `raid_tiers` has no unique constraint on `(expansion_id, name)`. Two simultaneous syncs for the same expansion could both insert. Accepted: the new-guild path runs once inside guild creation and the admin script is one owner-run process that ends with a duplicate-name check (plan 02-10). A unique index needs a migration and belongs with PLAT-06.
- A2 (research): `is_active` is true for the first Forever raid only (Barrow Deeps), mirroring the legacy `index === 0` rule. `is_active` drives "current phase" highlighting; confirm with the owner or switch to all true.

For the add-expansion route a zero-tier Forever expansion row can remain; the admin script (D-08, D-10) heals it, and that is exactly today's state for every existing Forever guild.
- D-04 helper audit (planning 2026-10-13, revised 2026-10-14 after the plan check): `utils/raidIcons.ts` does collide (it maps "Onyxia's Lair" to the Classic Onyxia icon and "Hyjal Summit" to the TBC Archimonde icon with no expansion key), so plan 02-11 Task 3 adds an expansion-scoped lookup: a Forever tier resolves to a neutral icon, never the Classic or TBC art, with a test that a Forever "Onyxia's Lair" does not resolve to the Classic icon (owner decision 2026-10-14). `utils/bossImages.ts` also collides ('Onyxia' boss art), but boss images render only beside loot rows and Forever has none until Phase 5, so it is recorded in 02-CONTEXT.md `<deferred>` tied to Phase 5 loot rows (owner decision 2026-10-14), not treated as "no collision". `utils/bossOrder.ts` keys on boss names that only appear on loot rows; it rides the same Phase 5 trigger. `data/raid-catalog-names.ts` only chooses among one guild's rows for one item (already guild-scoped), and Forever guilds have no items, so no Forever entry is added (Claude's discretion item resolved).
