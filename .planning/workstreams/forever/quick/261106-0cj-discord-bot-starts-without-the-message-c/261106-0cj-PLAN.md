- isMessageContentIntentEnabled(env): true only when env.DISCORD_MESSAGE_CONTENT_INTENT is exactly the string `true`.

- messageDescription(content): the trimmed content, or `(message text not available to the bot, see the Discord link below)` when content is null, undefined, empty or whitespace.
