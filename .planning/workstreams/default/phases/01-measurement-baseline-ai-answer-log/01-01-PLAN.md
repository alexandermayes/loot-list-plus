1. **MEAS-01 edge row 1 is `unclassified` and stays `unresolved`.** The edge probe could not assign a behaviour-shape category to "GSC baseline is exported and segmented into brand, competitor, problem, expansion query clusters", so it was not auto-resolved and it was not dismissed. The planner's working assumption, carried into this plan's `must_haves`, is that **the segmentation contract is total and single-valued**: every exported query row carries exactly one cluster value from a closed five-value set, and the five bucket counts sum to the total row count. If the intended contract is different (multi-label clustering, or excluding unclustered rows from the denominator when reporting cluster shares), MEAS-01's acceptance criteria need revising before Phase 6 reads the export.

Task 1 fixes brand, competitor, problem, expansion and records the reasoning in a code comment. It affects aggregation only; the raw per-query rows are unaffected, so a later change to the precedence is a re-run of the classifier, not a re-pull.

4. **RESEARCH.md Assumption A4 (public repository exposure) is accepted, not resolved.** Committing Search Console performance data to a confirmed public repository is competitive-intelligence exposure with no privacy dimension (no player or guild names). Recorded as threat T-01-03 with an `accept` disposition in plans 01-03 and 01-05.
