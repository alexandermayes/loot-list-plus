Extend the AI-answer instrument so the week-4 run can carry error types, and build the read-only grid that turns the log into the D-07 comparison the review quotes.

**As a** founder reading the week-4 review, **I want to** see each prompt's 3-surface result next to its Aug 28 result, with every miss labelled by what went wrong and which URL was cited, **so that** I can tell which pages AI answers are getting wrong and rank the fix.

The log has no error_type column today, and nothing reads the log back as a grid. Both must exist before the user runs the week-4 cells in plan 06-05.

Output: the extended appender and runbook, the updated log header, the grid script and its tests.
