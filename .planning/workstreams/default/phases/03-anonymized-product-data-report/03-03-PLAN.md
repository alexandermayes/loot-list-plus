<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Production aggregate to human console | Every computable candidate number, including ones that will never be published, is displayed here and enters this agent's context. This is the phase's widest disclosure surface. |
| Human decision to committed input | The selection file turns a conversational answer into a machine input that decides what the public page says. |
| Checkpoint response to artifact | A mistyped or hallucinated metric id would publish a finding the user never chose. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-15 | Information Disclosure | Candidate numbers the user declined being committed into `.planning/` or the artifact | medium | mitigate | `03-FINDINGS.md` records declined metrics by id and label with no number, and the runner emits only the ids listed in the selection file. The audit trail is the committed query plus the selection file, which regenerate the menu on demand. |
| T-03-16 | Tampering | A finding reaching the artifact that the user did not select | high | mitigate | The runner's only input is the committed selection file, and the verify block asserts the artifact's findings order matches that file id for id. Any id that is unknown, greyed, or support-kind is rejected before the file is written. |
| T-03-17 | Information Disclosure | The retention and privacy warning being skipped because a prior step already showed it | medium | mitigate | The warning is written into the checkpoint `<context>` itself, so it is displayed with the numbers rather than once at the start of the phase, and the stated business purpose is on screen beside it. |

| T-03-19 | Information Disclosure | A sub-floor segment reaching the console before the human can be warned | high | mitigate | The floor merge and the withhold rule run inside the runner before the menu renders, so a sub-floor segment is never displayed, and a withheld breakdown appears as unavailable with a reason naming the floor but not the segments. |
