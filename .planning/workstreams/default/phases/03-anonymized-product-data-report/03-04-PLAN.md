## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent-drafted prose to published claim | Anything approved here becomes a public statement carrying the user's byline and Person schema. |
| Approved string to committed source | Commits to main auto-deploy to production about 12 seconds after merge, so a string that drifts between approval and commit ships unreviewed. |
| Number token to rendered sentence | A token pointing at the wrong artifact path would put a real number in a sentence that does not describe it. |
