## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser URL -> /auth/callback | The next query parameter is attacker-controllable (anyone can craft a sign-in link) and decides where a freshly authenticated user is redirected |
| Browser URL -> /guild-select/create | The game query parameter is attacker-controllable and seeds client state |
| localStorage -> app and marketing UI | Storage may be missing, full, blocked or throwing (Safari private mode, disabled storage), and its values are user-editable |
| Client -> PostHog | Announcement events leave the browser |
| Root layout head -> every page | An inline script runs on every page load before hydration |
