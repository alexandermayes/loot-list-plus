- PD-07: remove-item today ignores the history insert error. The route now checks it, logs it with a constant format string (console.error with a fixed first argument, for CodeQL), calls trackApiError with user.id, and adds history_recorded (boolean) to the success response when already_obtained was sent. - PD-08: The remove-item builder sets no source key (the DB default 'web' still applies, as today) and no raid_event_id (as today). The route passes today as toDateString(new Date()), the same util it uses now, so awarded_date is unchanged.
