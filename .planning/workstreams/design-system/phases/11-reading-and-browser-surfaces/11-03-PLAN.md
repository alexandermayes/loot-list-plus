**Load-bearing mechanism finding (verified live).** Tailwind v3 tree-shakes *class*-selector rules out of a `@layer` block when the class appears in no scanned content file: compiling this file against a one-page content set emits `scrollbar-gutter`, the tabular-numerals rule and every `a[data-wowhead]` rule, but emits no `.nav-item-active`, `.card-gradient` or `.sidebar-scrollable`. All three of this plan's rules use non-class selectors and are therefore always emitted -- which is also why the sidebar's current class-scoped rules only reach the sidebar page bundles, and why generalizing to a universal selector is a real behaviour change, not a cosmetic refactor.
