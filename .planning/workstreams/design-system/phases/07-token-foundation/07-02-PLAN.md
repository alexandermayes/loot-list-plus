## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry to developer machine | The pinned devDependency is fetched and runs a postinstall that downloads a Chromium binary |
| Puppeteer process to local dev server | The script drives `/dev-login` and reads `/api/dev/test-users`, both dev-only routes |
| Captured PNGs and manifest to git history | Anything on screen or in the manifest becomes permanent once committed |
| process environment to logs and manifest | The dev server's Supabase variables and the seeded test-user credentials are in reach of the script |
