## Standing rules for every task in this plan

1. **One kind of diff per commit.** A batch commit contains the codemod's output for that batch plus the one-line ceiling decrement, and nothing else.
2. **The codemod is the author.** Never hand-edit a rewritten line. If the output is wrong, fix `scripts/codemods/text-sizes.mjs` or `scripts/codemods/text-size-map.json`, revert the batch, and re-run it. D-15 made the codemod idempotent and re-runnable per directory precisely so this is cheap.
3. **CI green per commit, not per phase.** `npm run lint`, `npm run typecheck` and `npm run test` all pass on every commit. If `npm run test` shows failures in files this batch never touched, re-run with `npx vitest run --maxWorkers=2` before concluding a regression (RESEARCH.md Pitfall 5, the diagnosed vitest worker-pool contention).
4. **Dry-run, read the report, then apply.** Every batch runs `--dry-run` first; the printed report is what the 09-08 evidence doc cites.
