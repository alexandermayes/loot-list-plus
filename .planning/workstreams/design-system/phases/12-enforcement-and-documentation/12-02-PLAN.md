## Facts this plan relies on (measured at plan time)

- `app/globals.css` declares 46 unique custom properties: 45 HSL colour tokens in both `:root` (line 131) and `.dark` (line 213), plus `--radius: 12px` in `:root` only. `--accent-subtle` is the only token with alpha (`/ 0.15` light, `/ 0.2` dark). `parseTokens` in `contrast.ts` drops alpha.
- The trailing `/* #rrggbb */` comments beside each token in `globals.css` are hand-typed and not authoritative: 07-04 found one wrong, and `--foreground: 220 20% 4%` converts to `#080a0c` while its comment reads `#09090c` (12-MEASUREMENTS.md item 7). The guard and the document compute hex from the HSL triplet and never read those comments.
- `tailwind.config.js` is CommonJS (`module.exports`); load it in Vitest with `createRequire(import.meta.url)`. `fontSize` has 29 keys, `borderRadius` 11 (`none, sm, DEFAULT, md, lg, xl, 2xl, full, pill-sm, pill, pill-lg`), `fontFamily` 3 (`sans, poppins, wow`), `spacing` extension 4 (`4.5: 18px, 5.5: 22px, 13: 52px, 15: 60px`).
- `app/layout.tsx` binds `Poppins({ variable: "--font-poppins" })`, `localFont({ src: "../public/fonts/FrizQuadrata.woff", variable: "--font-wow" })` and `Figtree({ variable: "--font-tabular" })` (lines 2-45).
- The detector's frontmatter parser (`design-system.mjs` `parseYamlSubset`, `parseScalar`) supports only block-style nested maps and scalars. A value that opens with a brace or bracket becomes a plain string, so the rule that depends on it silently abstains. The spec example in `.claude/skills/impeccable/reference/document.md` uses block style for every key; follow it.
- `context.mjs` today prints `EXISTING_VISUAL_SYSTEM` and no `# DESIGN.md` block (12-01 Task 1 recorded this live).
- With D-06's colour keys in the frontmatter, `app/components/KonamiEasterEgg.tsx:17` (`#ff8000`, the dark-theme accent, absent from a light-only frontmatter) is flagged by `design-system-color` in the immediate tier: the thinnest observable proof that the hook picked up DESIGN.md.
