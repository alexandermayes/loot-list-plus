# Quick 261013-w43: addon credits bad luck protection once per raid night (GH #355 item 3)

## Objective

The in-game bad luck protection (BLP) counter credits each raider who listed an item at most once per item per raid night, and never credits a raider who won a copy that night, matching the website. Two copies of one item on one night no longer double count. Ship as one PR to the addon repo.

## Context

- Code: `/Users/alexander.mayes/Code/personal/loot-list-plus-addon` (main at c22ebb9, 1.1.0). Run every command from that root. Tests: `/opt/homebrew/bin/luajit tests/run.lua` (60 pass today).
- Bug: `Modules/LootDistribution.lua` `LD:AwardItem` lines 162-174 call `DB:ResetBLP(winner)` then `DB:IncrementBLP` for every other priority-list entry, on every award. This is the only BLP write site. `LD:ManualAward` never touches BLP, and `LD:AwardToRollWinner` sends listed raiders through `AwardItem`, so `AwardItem` is the only change site.
- Website rule (`supabase/migrations/20260721000001_add_blp_reset_anchor.sql`, `recompute_blp_for_item`): one pass per contender per raid event where the item was awarded, and no pass at an event where that contender won the item. So the winner is marked for the night too; otherwise Thrall, who wins copy 1 and stays listed for copy 2 at his next rank, gets +1 when copy 2 goes to Jaina. The addon uses the raid date for the raid event.
- `guildData.blp` is replaced on every import (`Sync:ProcessImport` -> `DB:SetGuildData`), so the marker lives at profile level (like `pendingAwards`) and survives imports and /reload.
- Raid night: `LLP.Attendance.currentSession.raidDate` (UTC, set in `Att:StartSession`), else `U:GetDateString()` (UTC). `Modules/Attendance.lua` loads after `LootDistribution.lua` in the .toc and is not in `tests/harness.lua` `MODULE_FILES`, so LD reads `LLP.Attendance` at call time and falls back when it is nil. Tests stub `h.LLP.Attendance = { currentSession = { raidDate = "..." } }`; `H.fixClock(iso)` drives `U:GetDateString()` and `run.lua` resets the clock before each test.
- Accepted trade-off: if an import mid-raid carries a server count that does not yet include tonight, the addon does not credit tonight again locally; the next sync corrects it (the server is the source of truth).

```lua
-- Whether a raider's bad luck protection for an item is already settled on
-- this raid night (credited once, or won a copy)
function DB:WasBLPCredited(raidDate, lootItemId, characterId)
    local nights = self.profile and self.profile.blpCredited
    local items = type(nights) == "table" and nights[raidDate]
    local raiders = items and items[lootItemId]
    if not raiders then return false end
    return raiders[characterId] == true
end

-- Mark it settled. Only the current raid night is kept: marking a new night
-- drops every older one, so the table stays small.
function DB:MarkBLPCredited(raidDate, lootItemId, characterId)
    if not self.profile or not raidDate or not lootItemId or not characterId then return end
    local nights = self.profile.blpCredited
    if type(nights) ~= "table" then
        nights = {}
        self.profile.blpCredited = nights
    end
    for night in pairs(nights) do
        if night ~= raidDate then nights[night] = nil end
    end
    if not nights[raidDate] then nights[raidDate] = {} end
    local items = nights[raidDate]
    if not items[lootItemId] then items[lootItemId] = {} end
    items[lootItemId][characterId] = true
end
```

(Clearing existing keys inside `pairs` is allowed in Lua 5.1. The `type(nights)` guard covers 1.1.0 SavedVariables that have no `blpCredited` key.)

-- The raid night an award counts against for bad luck protection: the
-- attendance session's date while one is tracking, else today (both UTC).

function LD:CurrentRaidDate()
    local attendance = LLP.Attendance

    if session and session.raidDate then

    -- Update BLP locally, at most once per raider per item per raid night,
    -- as the website does (an item can drop more than once a night). The
    -- winner resets and gets no credit for a later copy tonight.
    local raidDate = self:CurrentRaidDate()
    DB:ResetBLP(characterId, item.lootItemId)
    DB:MarkBLPCredited(raidDate, item.lootItemId, characterId)

    -- Credit each other raider who had the item ranked, once tonight
    -- (attendance is not checked here: every listed raider is credited)
    for _, entry in ipairs(item.priorityList) do
        local other = entry.characterId
        if other ~= characterId and not DB:WasBLPCredited(raidDate, item.lootItemId, other) then
            DB:IncrementBLP(other, item.lootItemId)
            DB:MarkBLPCredited(raidDate, item.lootItemId, other)
        end
    end
